Execute Program 的课程很少用来提醒先前材料：它们短小而聚焦。每一课都是在这样的假设下写成的：读者已经学过并且记住了所有前置知识。而这个假设也会被阅读环境所强化：在你成功复习其前置课程之前，Execute Program 的课程不会解锁[1]。

我向 Gary Bernhardt 询问了这一假设会如何具体地影响他的写作。答案有点不清晰：Gary 原本就更偏好用这种风格来写——Execute Program 只是把它系统化了。

根据其界面上的说明：「这个假设让我们可以写出更短的课程，并且更少重复你已经学过的想法。它也会让你更不容易在新课程里卡住。」


Q. Execute Program 的课程如何强化「学生能回忆起所有先前材料」这一假设？
