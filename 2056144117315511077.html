方法说明

  • 每门语言运行核心 topic 查询、领域工具查询、语言别名/生态关键词查询。
  • 核心查询使用 topic:language-learning topic:<language> fork:true。
  • 领域查询不强制 language-learning，覆盖 dictionary、anki、popup dictionary、flashcards、language learning app、字幕句子挖掘和沉浸式学习工具。
  • 配置中的 seed 仓库通过 GitHub repository API 直接拉取，用于纳入不绑定单一目标语言的关键多语言工具。
  • 分类结果分为 primary、partial、exclude、needs_review；人工修订来自 manual_review.yml。
  • primary 表示主要服务于该目标语言；partial 表示多语言或通用学习工具中覆盖该语言。

偏差说明

  • GitHub topic 标注不完整，未打 topic 的核心项目只能依靠名称、描述或生态关键词命中。
  • GitHub Search API 有排序和 1000 结果窗口限制；默认每条查询只取前 100 个 stars 排序结果。
  • GitHub 默认搜索会排除 fork，本流程强制加入 fork:true 以避免漏掉 Yomitan 这类 fork 项目。
  • 多语言工具会推高部分语言热度，因此报告同时展示综合排名和严格单语言工具排名。
  • README 搜索默认关闭，因为 README 命中容易把资源列表、教程、示例仓库混入工具集合。
