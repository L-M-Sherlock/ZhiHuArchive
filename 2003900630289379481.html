https://www.executeprogram.com

Execute Program 提供由 Gary Bernhardt 制作的、关于编程工具的交互式课程。课程将讲解文字与可直接动手的编程题穿插呈现。类似于助记媒介[1]，该网站集成了一个间隔重复记忆系统[2]，用于随着时间推移重复课程任务。

  • 课程体验：
    • Execute Program 的课程根据读者的互动逐段展开正文[3]
    • 读者通过执行程序来回答 Execute Program 的交互卡片[4]
    • Execute Program 没有不可执行的卡片[5]
    • Execute Program 的卡片既是应用卡片，也是回忆卡片[6]
    • 多个例子可以使用同一段代码「preamble」——一种有用的领域特化
    • Execute Program 的课程相当短[7]
    • Execute Program 的 Python 课程有一个动态参考资料
  • 课程与系统结构：
    • 在你成功复习其前置课程之前，Execute Program 的课程不会解锁[8]
    • Execute Program 的课程假设你对先前材料有扎实的回忆[9]
    • 在 Execute Program 的复习中，错过的答案不会惩罚学生，除非他们「放弃」[10]
    • Execute Program 的进度机制强调完成新课，而不是延长回忆时长[11]

相关：助记文本可以在一段时间内分小段连载，根据读者的记忆情况排期[12]
