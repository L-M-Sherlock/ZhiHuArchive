你觉得Vibe Coding是昙花一现还是真的在改变编程这件事？

@Thoughts Memo

学校≠教育≠技能；文凭溢价=80%信号传递+20%人力资本

发表于 2026年07月23日

357 👍 / 22 💬

你点了一份外卖。

你的手指摸了一下屏幕，屏幕把电容变化传给驱动芯片，驱动芯片把信号打包，数据包穿过4G基站、光纤骨干网、云服务器、餐厅的打印机、厨师的抬头——最后黄焖鸡米饭送到你家门口。

这个链条，你理解了几步？

第一步和最后一步。

中间的一切，对你来说都是魔法。

你觉得这很正常。为什么？因为每一层都足够稳定，稳定到你可以忽略。

人类文明就是一摞黑箱。

App程序员不需要懂编译原理。

编译器作者不需要懂芯片设计。

芯片工程师不需要懂晶体管物理。

器件工程师不需要懂量子力学。

至于量子力学为什么管用——那是物理学家的事。物理学家其实也不清楚。

再往下就是人类知识的边界了。

每一层的人，都只负责自己的那一层。

下层是黑箱。信任它，用它。

每一次新黑箱出现，上一层的人都炸过。

汇编程序员骂 C：「不碰寄存器，出 bug 都不知道死在哪。」

裸机开发者骂操作系统：「中断向量表都不写？」

手写 HTML 的骂低代码：「这也叫建网站？」

每一次质疑的关键词都一样：不够硬核。

每一次历史的答案也一样：只要黑箱够稳定，效率赢。

现在，轮到「写代码」这一层被黑箱化了。

你不需要学 Python。不需要理解异步、闭包、内存泄漏。

你只需要对 AI 说话，AI 帮你生成代码。

这个东西叫 Vibe Coding。

我管它叫——

念咒语。

为什么是「咒语」而不是「许愿」？

许愿靠运气。你对神灯搓三下，等着。灵不灵看灯心情。

咒语靠精确。《哈利·波特》里赫敏纠正罗恩：这句咒语的重音在「奥」不在「加」。念错一个音节，羽毛不动。

你试过让 AI 写代码吗？「帮我写个网站」，出来的东西大概率没法看。「帮我写个个人博客，白色背景，Tailwind CSS，导航栏固定顶部，文章分页每页 10 篇，评论用 utterances，部署到 GitHub Pages」，结果一次过。

咒语的措辞必须精确。在正确的位置给约束。知道什么时候收紧，什么时候放手。出了问题改一个词就掰回来。

这不是被动许愿。这是主动施法。

「怎么念咒语」正在成为一项新的元技能。

谁会吃到这波红利？

大胆预测：懂怎么念咒语的人，将会像十年前懂编程的人一样，吃到最多的时代红利。这个东西没有学校能教。全靠自己摸索。

另外，学校不仅教不了技术，也教不了品味。

2015 年懂编程的人吃到红利，不仅仅是因为他们「会写代码」。全球当时几百万程序员，真正暴富的只有一小撮。那些人赢在哪？赢在判断力。 他们在移动互联网刚冒头时就看到了机会，在竞品反应过来之前把产品做完了。

「会写代码」是执行层。「知道该写什么」是判断层。判断层永远比执行层更稀缺。

现在 AI 把执行层的门槛踩到几乎为零。人人能生成代码。

那什么变稀缺了？

判断力。品味。对需求的嗅觉。

Excel 让所有人都会算账，「会算账」不值钱了——但「能从账本里看出业务问题」的人更值钱了。

美图秀秀让所有人都会 P 图，「会 P 图」不值钱了——但真正懂美感的人一个都没失业。

这届人类将会成为史上最会写代码的一批人。

在旧范式还没退场、新范式还没稳定的缝隙里，程序员两头都要会。既要能读懂AI的输出，又要能自己上手改。

他们是过渡一代，也是最全面的一代。

往后呢？

未来的程序员或许会像今天的半导体物理学家一样稀有。

不是因为他们不重要——恰恰相反，他们不可或缺。而是因为每一层只需要少数人来维护。

只有当那一小撮承担了维护黑箱的义务，大多数才能有不懂黑箱的权利。

这就是人类文明的分工方式。

但这次的黑箱不一样

以前的每一层黑箱，都有形式化契约。编译器把a+b翻成什么指令，有标准，确定。同一个程序编译十次，结果一样。出了问题可以顺着调用栈一层一层追。

LLM 没有这个。同一个 prompt 问十次，十段结构完全不同的代码。九个能用，一个有隐藏 bug。你分不出来。如果你不懂代码，那就更是一头雾水。

以前的黑箱是工厂流水线。LLM 的黑箱像一个厨师——你跟他说做条鱼，每次味道都可能不同。有时候惊艳，有时候翻车。你不尝就不知道做的好不好。

这就催生了一个新需求：审查者（试吃员）。 能快速扫一眼 AI 输出就判断质量的人。能嗅出安全漏洞的人。能在咒语反噬之前拦住的守门人。如果 vibe coding 继续扩散，这个需求会很具体，很迫切。目前这种能力集中在有经验的程序员身上。

未来会不会出现一种「代码审查师」——不需要从零写代码，但擅长给AI的活挑刺？答案大概率是 YES。

如果你觉得 Vibe Coding 是昙花一现

那么整个人类文明或许也是。

这句话不是在抬杠。你想——从基础物理学往上直到你手里的 App，每一层都是黑箱，每一层都依赖下一层的稳定性。而最底层（物理规律）到底为什么稳定、能稳定多久，人类不知道。

休谟说过，归纳法没有担保。农场主假说告诉我们，所有物理规律可能只是感恩节前的数据拟合——火鸡以为每天中午都有吃的，直到感恩节那天被宰。人类文明本身就建在未知地基上。

反过来说，如果你能接受文明在物理学的混沌地基上运转了几千年没塌，那你就应该对vibe coding保持耐心。

历史上没有一个黑箱是一出生就完美的。都是先用起来，再慢慢修。出餐口洒汤就修出餐口，黑箱发疯就治黑箱。

我们当下要做的，就是让 vibe coding 的出餐口更稳定。

半导体的预测精度到了百万分之一级别，失效模式被研究了几十年。LLM 的代码生成在不同场景下准确率从 95% 以上到 50% 波动，失效模式每天都在刷新。两种「不确定性」差了若干个数量级。混为一谈是范畴错误。

Vibe coding 现在的问题不在于「有不确定性」。任何事情都有不确定性。问题在于，它的不确定性还没被压缩到可管理的范围。

你的选择

最后，回到开头那条黑箱链：App程序员不需要懂编译器，编译器作者不需要懂芯片，芯片工程师不需要懂晶体管。未来，咒语师不需要懂代码。

但注意一件事：每一层黑箱都需要有人懂。

总得有那一小撮人在晶圆厂调刻蚀参数。总得有那一小撮人在维护编译器、操作系统、数据库——这些构成上层地基的东西。

文明意味着：不是每个人都有义务懂所有事。但每一层，都必须有那一小撮人，把「别人不懂的权利」扛在自己肩上。

咒语时代来了。

你是愿意做念咒语的人，还是做那个维护下层黑箱的人？

这决定着你的教育方向。或者说辍学偏好。

最后：这一切的前提是AI不会先把人类搞死。那是另一个话题。我们改天再聊。

（2026年7月23日，咒语目前还能正常生效，AI 暂时没有发疯的迹象。）
