在 Execute Program 的复习中，错过的答案不会惩罚学生，除非他们「放弃」

@Jarrett Ye

钻研人类记忆，探索复习算法。改善教育公平，践行自由学习。

发表于 2026年02月03日

Execute Program 的间隔重复记忆系统[1]卡片是机器判分的，因此如果读者在回答中出现语义上无关紧要的拼写错误，系统也会把卡片判错。这种假阴性会非常恼人，尤其是因为在你成功复习其前置课程之前，Execute Program 的课程不会解锁[2]。在 SQL 课程中，假阴性率高到足以促使系统在 2020 年初进行修改：只要学生最终能给出正确答案，不正确的回答就不再被「算作」失败。读者可以想尝试多少次就尝试多少次，而下一次复习的间隔仍会按 SRS 曲线增加。后续课节的解锁也不再取决于用户表现。

如果用户在尝试多次后仍无法给出答案，他们最终可以点击「放弃」来查看正确答案。如果他们以这种方式放弃，那么该问题的间隔会像 SRS 中常见的「遗忘答案」那样缩短。

另见：自主评分的间隔重复记忆系统可避免假阴性[3]以及间隔重复记忆系统中的自主评分与机器评分。
