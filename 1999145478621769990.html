Execute Program 的课程根据读者的互动逐段展开正文

@Jarrett Ye

钻研人类记忆，探索复习算法。改善教育公平，践行自由学习。

在 Execute Program 中，你无法一次性读完整个课程：你读一两段，然后按下「继续」按钮，接着又会出现一两段，随后你会遇到一张交互卡片。一旦你完成了这张卡片，下一部分的文本内容才会呈现出来。这是一个紧凑的输入/输出循环，具有稳定的节奏。

这种细粒度的循环与读书完全不同，读书时读者可以控制节奏和深度。在传统的在线书籍中，所有文本始终都是呈现出来的；唯一的互动就是滚动。滚动是连续的，而 Execute Program 的步骤是离散的，且在过程中系统会为你自动滚动。前者确实让人感觉明显更舒适。从这个意义上说，Execute Program 更像是在模仿一场对话，不过是一场你只能点头并照做的对话。参见交互是界面设计中的成本中心[1]。

但这种设计确实创造了一种高度一致的阅读体验。在助记媒介（Mnemonic medium）[2]中，你可以自由地滚动并通读全文。在「阅读模式」和「交互模式」之间切换需要你停止滚动，并去点击复习框。从这个意义上说，交互卡片在 Execute Program 中感觉比在助记媒介中更「契合」：Execute Program 课程的每一个「片段」，无论是阅读还是回答卡片，都需要互动，因此感觉比在助记文章中少了些「切换感」。

同样，在助记媒介中，读者有可能「跳过」复习区域，无论是无意还是有意的；这给读者制造了需要额外留意的状态。Execute Program 的课程是线性的；读者只需跟着流程走即可。

情景体验需要由参与者的行动控制[3]；那么 Execute Program 是一种情景体验（Enacted experience）[4]吗？不：情景体验需要由参与者的行动控制[5]。


Q. 在 Execute Program 中阅读课程文本的体验与阅读书籍文本有何不同？
A. 它会随着用户的互动逐段展开。你无法一次性阅读全部内容。

Q. 为什么交互卡片在 Execute Program 中感觉比在 Quantum Country 中更「契合」？
A. 在 Execute Program 中，阅读本身就需要互动，因此交互卡片不需要你切换成一种交互姿态。
