人人都是 Thoughts Memo

这个项目一开始只是我个人备份用的，后来 vibe coding 实在太方便了，就让 codex 写了检索功能，还把文章全部整理到了 NotebookLM，可以很方便地用我们汉化组翻译的内容来写东西，所以就有了这个项目的名称《人人都是 Thoughts Memo 》。

日语打字练习

AI Works - 知乎

这个是基于 keybr 的盲打练习网站改的日语罗马字输入练习网站，由于我没怎么写过前端代码，所以依然是 codex 代劳，我只负责测试，以及补充一些关键的背景资料。最近进行了重构，之前平假名和片假名共享统计数据，导致系统高估了用户的片假名响应能力，现在这个版本解决了这个问题：

除了这两个项目，其实我还 vibe 了挺多日语学习小工具，这里就只发 GitHub 链接了：

jlpt-coverage

一个用来标记日语单词对应的 JLPT 等级的小工具，数据源来自 egg rolls 的 JLPT 备考牌组。

inline_css_cleanup

一个用来对卡片 css 去重的插件。

pin-definition-by-underline

一个用来帮我置顶日语卡片中词典释义的小脚本。

japanese-reading-stats

一个用来可视化我日语阅读记录的小脚本。

japanese-mining-report

一个用来可视化我日语查词背词记录的小脚本。
