在你成功复习其前置课程之前，Execute Program 的课程不会解锁

Execute Program 的学生无法立刻访问一门课里的所有课节。课程中的大部分课节一开始都是「锁定」的。这些课节依赖该课程中的其他课节：最初会解锁的课节只有{在该课程中没有依赖项的那些}。只有当{其所有依赖项不仅已经被阅读，而且也在近期被复习过（通过内嵌的间隔重复记忆系统[1]机制）}之后，课节才会解锁。

这让课程设计者能够写出更聚焦的课节：Execute Program 的课程假设你对先前材料有扎实的回忆。

下面是他们的 UI 对这一机制的解释：

这种做法提示了助记媒介可调整为将创制经验逐步展开的形式[2]的一个实例：与其写一本教科书，不如写一串高度聚焦的课节，并在学习者巩固知识的过程中，随着时间推移把它们推送给学习者。但：高效复习安排与过关式课程序列相冲突[3]

Q. 为什么 Execute Program 的课节会一直锁定，直到学生完成其前置课程？
A. 为了让课节可以写得高度聚焦，并且不需要对那些前置课程做任何提醒。
