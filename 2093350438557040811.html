排除超自然

@Thoughts Memo

学校≠教育≠技能；文凭溢价=80%信号传递+20%人力资本

发表于 2026年10月13日

24 👍 / 4 💬

偶尔，你会听到有人大声疾呼：神创论（creationism）绝不应该被放进学校的课堂里，更不应该作为与进化论并驾齐驱的竞争假说来教授，因为神创论引用了「超自然」的概念，所以它在先验（a priori）层面上就自动被排除在科学的考量之外了。

那么……他们这番话的意思难道是说，神创论可能是真的，但即使它是真的，你也被禁止在科学课上教授它，就因为科学只管「自然」的事物？

很显然，这种说法源于人们想要避免科学与宗教发生正面冲突[1]的避战心理。你不想直白地站出来说：「科学不教宗教主张 X，是因为 X 已经接受了科学方法的检验，并被证实是错的。」为了避开这层锋芒，你只好……呃……宣称科学在先验层面上就直接拒绝了假设 X。这样一来，你就不必去直面那些通过实验在后验（a posteriori）层面上狠狠打脸了 X 的客观事实了。

当然，这种回避态度正中神创论者的下怀：他们顺势控诉「智能设计论（Intelligent Design）」没有得到科学界的公平对待——他们说科学界在完全不看证据的情况下，就为了袒护无神论而预设了偏见。如果科学真的是在先验层面上就直接把智能设计论踢出局，那他们的这通抱怨还真是完全合理的！

但让我们先退一步。如果有人跑来对你说：「智能设计论被先验地排除了科学的范畴，因为它是『超自然』的，而科学只处理『自然』的解释。」

他们口中的「超自然」到底是个什么意思？难道任何一个姓「科恩」的人提出来的解释，就自动算是超自然的吗？如果我们要简单粗暴地把一整套假设踢出科学界，我们到底是在排除什么特征？

到目前为止，我听过的关于超自然最精准的定义，当属理查德·卡里尔的概括：「超自然」的解释，诉诸于那些在本体论层面上不可再分的纯精神实体（ontologically basic mental things），即那些绝对无法被进一步还原为非精神机制的精神幽灵。

打个比方，这就是说水往下流是因为它“想”流向低处，与提出一组只描述纯粹物理运动、绝不牵涉任何意图欲望的微分方程之间的区别。这就是说一棵树长出树叶是因为「树精」在施法，与深入研究植物生物化学机制之间的区别。认知科学已经把反对超自然主义的战火，烧到了心智的最深处。

为什么说这是一个绝佳的超自然定义呢？完整的论证过程我建议你去读读理查德·卡里尔的原文。但你不妨设想一下：假设你真的发现了一个疑似栖息在树上的精神实体——一个不仅能化为人形在树外飘荡，还会用英语跟你高谈阔论保护森林重要性的树神（dryad）。然后，假设我们把显微镜对准这位树神，结果发现她其实也是由各种微小零件组装而成的[2]——并且这些零件并非什么天生自带灵性、不可言喻的「欲望之线」或「信仰之布」，而全都是跟夸克、电子属于同一类性质的零件，它们的运作法则完全由物理运动而非主观心智来定义。如果是这样的话，这位神圣的树神难道不会瞬间跌落神坛，被归入沉闷乏味的凡物名录[3]之中吗？

但是，一旦我们接受了理查德·卡里尔对超自然的定义，一个两难的困境就随之而来了：我们很想给宗教主张一个公平验证的机会，但按照这个定义，我们似乎又有极其充分的理由，在先验层面上就直接把所有超自然的解释统统判死刑。

我的意思是，如果还原论真的是错的，那这宇宙该长成什么鬼样子？

我之前是这么定义还原论的核心论点[4]的：人类的心智创造出了关于现实的多层级模型，在这个模型中，高层级的模式和低层级的模式是被分开、被显式地独立表征出来的。一位物理学家同时掌握着牛顿的引力方程和爱因斯坦的引力方程，并知道前者不过是后者在低速状态下的近似推导。但这三种彼此独立的心智表征，仅仅是为了照顾人类认知能力的局限而诞生的捷径。这绝不意味着现实宇宙本身有一套在高速下管用的爱因斯坦方程、另一套在低速下管用的牛顿方程，外加一条用来平滑过渡的「桥接法则」。现实宇宙本身只有一个纯粹的底层，那就是爱因斯坦的引力系统。仅仅是因为人们犯了心智投射谬误[5]，才导致一些人误以为认知模型里的更高层级也能脱离底层、独立存在——现实的不同组织层级当然可以在人类的认知地图上拥有独立的表征标签，但这片疆域本身，却是一个单一、统一、不可分割的底层数学实体。

假设上面这段话全错。

假设心智投射谬误[5]根本不是谬误，而是确凿的真理。

假设一架波音 747，真的拥有一种完全独立于构成它的夸克之外的、最基础的物理实体存在。

如果你发现自己身处于这样一个宇宙里，你预期会观测到什么样的实验现象？

如果你连这个问题都答不上来，那真正把「非还原论」信念踢出局的，根本就不是什么实验观测，而是它在先验逻辑上的荒诞与不连贯（incoherence）。如果你连「非还原论」模型会做出什么预测都说不上来，你又怎么能说它是被实验证据排除掉的呢？

我的核心论点是，非还原论纯粹是一团逻辑上的混淆；而一旦你意识到某个想法本质上就是个缝合怪般的混淆概念，你就会发现，想要在脑海里勾勒出「如果这个混淆为真，宇宙会长什么样」，简直是难于登天。也许我的脑子里装了一个多层级的世界模型，而且这个多层级模型竟然与物理世界的底层因果元素存在着魔法般的「一对一直接映射」？可一旦你把所有的运作规则都列明清楚了，这个模型为什么不会直接被拍扁，重新变回另一份「基本实体及其交互作用的清单」？难道我在认知模型中能看到的每一个概念，比如一架 747 或者一个人类心智，都非得在物理上变成一个独立的真实存在物吗？那如果我在那个新诞生的超级大杂烩系统里，又看出了某种新模式呢？难道还要接着套娃吗？

超自然主义其实就是非还原论的一个特殊变种：在这个版本里，那些「不可被还原的实体」不是 747 飞机，而仅仅是（某些）纯精神的概念。宗教则是超自然主义的进一步特例：在这个版本里，不可还原的纯精神实体被具象化为了上帝、灵魂；可能还附带上了罪孽、天使、因果报应（karma）等等。

如果我提出，存在一个无比强大的实体，它有能力监视并随意篡改我们这个可观测宇宙中的每一个元素；但这个实体本身依然可以被还原为非精神的物理零件，并且它与我们宇宙元素的交互完全符合某种客观物理法则；如果我提出这个实体确实「渴望」发生某些特定的事，但它产生「渴望」的过程，依然是依赖于一个由粒子和力场构成的大脑；那么，这根本算不上什么宗教，这充其量不过是关于《黑客帝国》母体（Matrix）的一个自然主义假说罢了。如果明天风云突变，一个巨大、发光且没有固定形态的巨人出现在云端，用雷鸣般的声音宣读了上述这段关于它自身现实的描述，这当然不能证明它说的每一个字都是实话；但我绝对会把这段录像搬进科学课堂，并且我会绞尽脑汁试图从这个「上帝理论」中推导出可被实验检验的预测。

相比之下，宗教界却对那个古老的、没有实体的伟大存在[6]视而不见：那个无处不在地主宰着大自然运转、内在于每一片落叶之中；身躯如行星表面般广袤、拥有数十亿年高龄；它自身未经任何神明创造、纯粹是从冰冷的物理结构中自发涌现；它没有大脑、没有意识，却雕刻出了地球上所有的生命以及全人类的心智。当达尔文提出「自然选择」时，宗教界可没有把它当作期待已久的造物主来顶礼膜拜：因为自然选择，在最底层的基础层面上，是毫无精神属性的。

但现在，两难的困境来了：如果目前关于物理学和大脑的那套稳重、传统、常规且乏味的认知是正确的，那么一个人类在原则上就不可能在脑海中具体、真切地设想出一个「事物不可被还原为非精神实体」的替代宇宙，更不可能从中推导出可检验的实验预测。因为，如果那套乏味而古老的常规科学模型是对的，你的大脑本身就是由夸克构成的；因此，你的大脑只能去设想和预测那些同样由夸克决定并能预测的事物。你永远、永远只能构建出那种「由简单事物相互作用」拼接而成的模型。

生活在还原论宇宙中的人，是无法在脑海中具体构建出非还原论宇宙的样貌的。他们当然可以用嘴皮子吐出[7]「非还原论」这几个音节，但他们的大脑根本无法真正去想象（建模）它。

之所以会产生这种拟人化的根本错误，之所以超自然的解释听起来总是比现实显得简单得多[8]，是因为你的大脑把「自己」当成了一个不透明的黑匣子，直接拿来去预测其他被贴上「有心智」标签的事物。因为你的脑袋里早就装好了庞大、复杂、运转如飞的神经网络硬件，用来执行你「渴望」某物的欲望；所以，当你描述水「渴望」流向低处时，你觉得这解释简直太通顺、太容易理解了——「渴望」这个简单的词汇就像一根拉杆，瞬间就启动了你自己大脑里那套极其复杂的欲望计算机器。

或者，你幻想着上帝喜欢美丽的东西，因此创造了鲜花。你自己大脑里的「审美」电路，极其丝滑地判定了什么是「美」，什么是「不美」。但你根本不知道你自己大脑突触的连接图谱。你无法用语言描述一个非精神的物理系统，是如何经过精密计算，最终为某个事物贴上「美」或「不美」的标签的——你根本写不出一个能精准预测你自己审美偏好的计算机程序。但这仅仅是你自己在知识储备上的缺陷；这绝不意味着大脑的运作根本不存在物理上的解释[9]。

如果关于现实的这套「乏味科学观点」是正确的，那么你永远无法预测任何「不可被还原」的东西，因为你本身就是可以被还原的。你也永远无法为「不可还原性假说」提供任何贝叶斯证据上的确认，因为任何你能做出的预测，必然也是一个可被还原的物体（即你的大脑）能够预测出来的。

有些思想的铁盒子，你是真的没法跳出其中去思考的。如果我们的宇宙真的是一台图灵可计算的机器，我们将永远无法具体地设想出任何非图灵可计算的东西——无论我们的数学家在口头上能谈论多少层「停机预言机（halting oracle）」的逻辑层级，我们也永远无法实际预测出一个真正的停机预言机到底会说什么，从而在实验中把它与一台普通的可计算推理机区分开来。

当然，所有这一切的前提，都是假设「乏味的科学观点」是正确的。在多大程度上你相信进化论是真的，你就不应该预期会遇到反驳进化论的强有力证据。在多大程度上你相信还原论是真的，你就应该预期非还原论的假说不仅是错的，而且根本就是逻辑不连贯的（incoherent）。在多大程度上你相信超自然主义是假的，你就应该预期它在心智上同样是无法被真正想象的（inconceivable）。

另一方面，如果某个超自然假说最后竟然被证明是真的，那么想必你也会同时发现，它其实并非无法想象。

所以，让我们把思绪绕个大圈，回到智能设计论（ID）的问题上来：

智能设计论是否应该因为援引了超自然概念、把自己排除在了自然哲学的范畴之外，从而被先验地（a priori）剥夺接受实验证伪的资格，并被永远踢出科学课堂？

我的回答是：「当然不应该。」 智能设计者的不可还原性，根本就不是 ID 假说中不可或缺的组成部分。对于 ID 支持者们能脑补出的每一个不可还原的上帝，都必定存在着一个对应的、可被物理还原的「外星人」，并且这个外星人的行为完全符合相同的预测——毕竟 ID 支持者他们自己就是可被物理还原的。既然我在极大程度上深信还原论就是事实，我就必须预期：对于所有那些挂着超自然羊头卖狗肉的预测模型，我总能找到它们在底层完全可被物理还原的对应表述。

如果我们要去翻找考古记录，来检验「耶和华为了公开展现其超自然伟力而把红海劈成两半」这个断言，那么耶和华到底是在本体论上不可再分的神，还是一个掌握了顶级纳米技术的外星人，亦或是《黑客帝国》里的某个黑暗领主，根本没有任何区别。你组织考古队去挖一挖，发现红海遗址里连一根埃及士兵的骨头残骸或一块生锈的盔甲都没有，并且查阅历史记录发现，当时的埃及实际上正统治着迦南的大片领土。于是，你在这个圣经历史记录上盖上「已被证伪」的红章，然后继续你的生活。这个假说在逻辑上是连贯的，它是可证伪的，并且它被证明是错的。

生物学中那些铁证如山的证据也一样：狐狸被进化塑造成了追捕兔子的杀手，兔子被塑造成了躲避狐狸的逃犯，并且它们中没有一个是哪怕有一丁点意图为了「延续它们的物种」或「保护大自然的和谐」而设计的[10]；同样，视网膜竟然被反向设计，导致感光部分被奇葩地压在最底层的证据也一样；以及成千上万个证明这个设计者思维分裂、毫无道德底线且极其无能[11]的其他证据。我们关于这个异形外星上帝[6]的「耶和华模型」，在逻辑上是连贯的，是可证伪的，并且是错的——只要你不在乎耶和华在本体论上到底是不可再分的神还是仅仅是个外星人，它就是逻辑连贯的。

你只需要把那个超自然假说，直接翻译成对应的自然主义假说就行了。按照完全相同的方式做出完全相同的预测，绝口不提任何「精神实体在本体论上是基本存在」的废话。如果需要做出预测，大可以直接调用你大脑里的黑匣子——比如说，如果你想探讨一个「愤怒的神明」，你并不需要真去从头搭建一个拥有完备感情模块的人工智能来判定哪些行为属于「愤怒」，哪些不算。所以，你要么直接推导出预测，要么去查阅那些古代神学家在根本无从知晓现代实验结果的前提下所做出的预言。如果现代实验的结果与那些预言发生了冲突，那么我们完全有理有据说：这个宗教主张在科学上已经被彻底驳倒了。它得到了公平的证实机会；它是被后验（a posteriori）的证据踢出局的，而不是在先验的偏见上被拒之门外的。

归根结底，还原论仅仅是不相信那些在底层根本上极其复杂的事物。如果「根本上极其复杂」这个词听起来就像个自相矛盾的词语搭配（oxymoron）……嗯，这正是为什么我认为非还原论的教条纯粹是一团认知上的混淆，而不是某种「宇宙本来有可能长这样，只是恰好没长这样」的物理可能性。如果你发现自己的脑海中开始冒出这类想法，那你最好小心点。

科学的终极铁律就是：去观察，去看。如果某天真的有一个上帝降临在群山之巅雷鸣般地咆哮，那这也是人们可以用肉眼去观察、去看清楚的客观现象。

推论： 任何一个所谓通用人工智能（AGI）的设计者，如果他用极其恭敬、肃穆的语调来谈论宗教信仰[12]，那他绝对不是一个懂得如何将心理认知概念还原为冰冷物理实体的专家；事实上，这说明他对认知科学最底层的常识都匮乏到了极点，以至于我们几乎不可能相信他在这门将心智转化为代码的艺术上是个什么专家；除非他患有绝对重度的「白痴天才综合征」（idiot savancy）。当然，如果他纯粹是在大庭广众之下满嘴跑火车撒谎，那就另当别论了。我们在这里谈论的可不是什么微不足道的小失误。
